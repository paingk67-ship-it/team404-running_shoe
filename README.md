# Team 404: Data-Driven Value Assessment of Running Shoes

Streamlit app for price vs. performance analysis, K-Means clustering
and Random Forest feature importance.

## How to run

1. Install Python 3.10+ and Git
2. Clone and enter the project:
   git clone https://github.com/YOUR-USERNAME/team404-running_shoe.git
   cd team404-running_shoe/404
3. Create and activate a virtual environment:
   python -m venv .venv
   .venv\Scripts\activate          (Mac/Linux: source .venv/bin/activate)
4. Install libraries:
   python -m pip install -r requirements.txt
5. Run the app:
   python -m streamlit run app.py

(Optional) Regenerate the dataset: python generate_data.py
